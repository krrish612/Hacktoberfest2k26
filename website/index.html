(FAQ) Questions nobody asked
Is there a live demo?

No. There is no demo. There is a button that says “Watch the demo” and it does nothing. That is the demo. (Parody trope: “no real demo.”)

Does it use AI?

Yes — a local vision model served by Ollama on 127.0.0.1. It does not phone home. It cannot; there is no phone.

Where is my data?

In an SQLite database and an evidence folder inside the app's private data directory on your machine. Not on a server, because there is no server.

Is this really a parody?

Yes. Everything decorative — the testimonials, the pricing, the stats, the “wall of love” — is fictional. The descriptions of how the real app behaves are accurate. See the banner at the top.
